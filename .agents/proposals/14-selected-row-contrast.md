选中表格行后,行内的次要文字和胶囊几乎看不见

## 现状

`internal/ui/ui_view.go:379-381` 选中行只替换 `Accent`/`AccentText` 两个颜色,其余颜色保持主题原值:

```go
tint.Accent, tint.AccentText = chosenRow(t), t.Text
```

## 实测(已用测试验证)

| 组合 | 比值 | 要求 |
|---|---|---|
| 深色弱化文字 `#99a1ac` 对选中行 `#324955` | **3.63:1** | 4.5:1 |
| 浅色成功色 `#0f7b0f` 对选中行 `#dbe9fb` | **4.42:1** | 4.5:1 |
| 「服务发现」胶囊底对选中行(浅) | **1.11:1** | 需可辨 |
| 「服务发现」胶囊底对选中行(深) | **1.25:1** | 需可辨 |
| 选中行本身对白卡 | **1.23:1** | 与悬停 1.08 难区分 |

胶囊在选中行上直接「消失」,只剩几个字浮着。

## 方案

在 `hostTree` 里把选中行版本的 `TextMuted`、`Success`、胶囊底色一起改掉:

- 深色 `TextMuted → #b9c2cc`(对选中 5.25)
- 浅色 `Success → #0b6a0b`(5.54)
- 「服务发现」选中态改描边胶囊(1px 描边 + 透明底)
- 选中底色加深:浅 `#cfe2fa`、深 `#2f4f63`

## 验收

- 打印选中行内各前景色对选中底色的比值,全部 ≥ 4.5
- 截图中选中与悬停一眼可分,胶囊轮廓清晰
