「这台 192.168.1.7 是什么设备」现在只能靠用户自己拼线索

## 现状

详情里给的是主机名、厂商、MAC、NetBIOS 名、服务、端口。没有任何一句话说「这是一台打印机」。

## 方案

用已有数据推断,纯界面层,不动契约:

| 线索 | 类型 |
|---|---|
| 网关 | 路由器 |
| `_ipp` / `_printer` 或 9100/515/631 | 打印机 |
| `_rtsp` 或摄像头厂商 | 摄像头 |
| 445/548/5000 | NAS |
| `_airplay` / `_googlecast` | 电视 / 投屏 |
| 其他 | 电脑 / 手机 / 未知 |

- 详情头给中文类型
- 表格 IP 旁给小图标或短标签
- 图标自绘 SVG,不引图标字体

## 风险

- 误判:通用 OUI、只扫了常用端口 → 低置信时显示「未知」,不硬猜

## 验收

- 扫到路由器 / 打印机 / 电脑时,类型正确
- 无任何线索的地址显示「未知」
