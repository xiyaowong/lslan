网卡读取失败后永远停在「正在加载网卡…」

## 现状

失败分支只写错误,不改变 `nics`,而界面用 `nics == nil` 判断「还在加载」:

- `internal/ui/app.go:307-315` 失败时只 `a.scanErr = ...`,直接 return
- `internal/ui/ui_view.go:143-144` `case a.nics == nil:` → 「正在加载网卡…」
- `internal/ui/ui_view.go:292-294` 错误只渲染在状态栏

## 后果

读取网卡失败后,网卡区**永远**显示「正在加载网卡…」,与状态栏的「读取网卡信息失败,请重启程序试试」互相矛盾。没有重试入口,只能重启程序。小窗口下状态栏错误还会被挤成省略号。

## 方案

1. 失败时置为空切片(而非保持 nil),界面走 `default` 分支
2. 该分支显示「没有读到网卡」+ 一个「重试」文字按钮,点击再次调用 `listNICs`
3. 状态栏不再承担这个错误

## 验收

- `listNICs` 返回错误后,帧内出现「重试」,不再出现「正在加载网卡…」
- 点重试会再调一次 `listNICs`
