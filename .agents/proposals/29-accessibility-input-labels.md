读屏无法区分「开始地址」与「结束地址」

## 现状

- `internal/ui/ui_view.go:132-136` 网卡下拉只有视觉标签,控件本身没有 `.Label("网卡")`
- `internal/ui/ui_view.go:216,220` 八个格子统一叫「IP 第 N 段」,第 5–8 段完全不知道属于结束地址
- 扫描进度条、主机树都没有 Label

## 方案

- 网卡下拉 `.Label("网卡")`
- 第 1–4 段改名「开始 IP 第 N 段」,第 5–8 段改名「结束 IP 第 N 段」
- 进度条 `.Label("扫描进度")`,主机树 `.Label("主机列表")`

## 验收

- 无障碍树中下拉名为「网卡」
- 八个输入框名称能区分开始/结束
- 进度条与表格有名称
