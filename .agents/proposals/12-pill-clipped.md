服务发现徽标被挤成 0 宽

## 现状

表格 IP 列固定 184(最小 168),行内依次是:圆点 8 + 间距 8 + IP + 间距 8 + 「网关」胶囊 + 间距 + 「服务发现」胶囊。胶囊是 `Shrink(0)`,列放不下时只会被裁切。

## 实测

用 15 字符 IP(`192.168.3.254`)+ 网关 + 服务发现,在默认窗口下测得的宽度:

```
"网关"       x=156.8  w=22.0
"服务发现"   x=202.8  w= 0.0   ← 完全没了
```

「服务发现」宽度为 0,即被完全挤出。默认卡宽下路由器的「网关」徽标也已贴到列边。

## 方案

三选一(建议 1):

1. 把两个徽标移出 IP 列,并入「主机名」列,或改成 IP 后的 11px 纯文字后缀
2. IP 列宽改 220 / MinWidth 200,胶囊内边距缩小到 `Padding(1,6)`
3. 徽标折到第二行(行高从 36 变高,不推荐)

顺带:MAC 列 `Width:132` 且没有 `SingleLine()`/`Tooltip()`,窄卡下会硬裁,应补省略号与悬停全文。

## 验收

- 最坏情况(15 字符 IP + 两个徽标)在最小卡宽 400 下,两个徽标完整可见
- MAC 在最小列宽下以「…」结尾且有 Tooltip
